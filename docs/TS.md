# ТЗ

Исходный код размещен в https://disk.yandex.ru/d/dq7DnhDesOpZrA

Требуется переписать программу с `Python` на `Go`, выполнив ряд доработок:

1. `calculator_server`
    - Требуется отвечать на http запрос к роуту `POST /calc?num=X` максимально быстро.
    - Сделать роут `/metrics`, который будет возвращать в формате prometheus:
        - rps http запросов за каждую секунду из последней минуты (60 значений за последние 60 секунд с rps)
        - p95, p99 времени выполнения вызова функции на C
        - p95, p99 времени выполнения вызова функции на Rust

2. `generator`
    Переписать программу на `Go`.
